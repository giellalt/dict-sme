Drøfting av ord å definere
==========================

Dokumentet ser på ulike måtar å ordne og prioritere ordforrådet som
skal definerast.

## Prinsipp for gruppering
- alfabetisk
- etter frekvens
- etter semantikk
- etter type

## etter semantikk

Måten å finne semantiske felt på:
1. Finn ei semantisk avgrensa liste på norsk
2. køyr den gjennom `nobsme` og få samiske ord
3. køyr den gjennom `smedef` og sjekk om det allereie er definert
4. skriv definisjonar

Moglege kjelder:

- Gyldendals visuelle ordbok
- Yann de Caprona: Norsk etymologisk ordbok tematisk ordnet
- De første 1000 ord (på samisk)
- ...
